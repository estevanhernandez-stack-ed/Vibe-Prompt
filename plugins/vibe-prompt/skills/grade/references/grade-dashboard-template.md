## Rendering rules

- Status arrows: ↑ (improved), ↓ (regressed), = (stable), · (no prior baseline).
- Per-dimension cell indicator: 9-10 = ✓, 5-8 = ·, 1-4 = ⚠.
- Flagged regressions section: render at top of the dashboard (above per-prompt table) if any
  regressions exist — don't bury the bad news.
- If eval results were absent (audit-only grade), add a note at top: "⚠ Eval results absent —
  grades computed from audit scores only. Run /vibe-prompt:eval for behavioral dimension data."
- If `--accept-regression` was used, add: "Note: regression override applied via --accept-regression.
  Baseline advanced despite regression. Friction-logged."
